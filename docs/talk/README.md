## Code viewer

Click any source path on a slide (e.g. `internal/eth/ethernet.go`) to open the
repo in a Monaco editor over the deck, scrolled to and highlighting the code on
that slide. Browse other files from the tree, use A−/A+ for text size, then
**Esc** to return.

Locally (`make talk` / `serve.py`), files come from your working tree and
“Open in Cursor” jumps to the same line in the IDE. On GitHub Pages, files are
fetched from this repo over the network and the button opens the file on GitHub
instead. The tree only lists `cmd/`, `internal/` and `scripts/` (`.go` / `.sh`);
no markdown or top-level docs. Refresh `src-index.json` with `make talk-index`
after adding sources.

Sources: [presentation.md](../presentation.md), [layers-and-onions.md](../layers-and-onions.md).

Needs network once for Reveal.js + fonts CDNs (or vendor locally later).

## Hexdump slides

The "real bytes" slides are generated by `hexdumps.py` from frames
captured in the lab (inside `make shell`):

```bash
/tmp/mytcp -i tap0 -app http -dump=false -pcap captures/talk-http &
ping -c 1 10.0.0.2 && curl http://10.0.0.2/          # then stop mytcp
/tmp/mytcp -i tap0 -app https-diy -dump=false -pcap captures/talk-https-diy &
curl -k --tlsv1.2 --tls-max 1.2 https://10.0.0.2/    # then stop mytcp

# any frame, as hexdump -C:
jq -r 'select(.n==7).data' captures/talk-http.jsonl | xxd -r -p | hexdump -C
```

`captures/` is gitignored, so the frames are copied into `FRAMES` in
`hexdumps.py`. After changing them or the field colours, run
`python3 hexdumps.py`; it rewrites the slides between the
`<!-- hexdump:NAME -->` markers in `index.html`.

The preamble also includes a real `curl -4 http://google.com/` capture
from Docker (`strace` + `tcpdump` on `eth0`, port 80). Plain HTTP on
purpose: the HEAD and the 301 redirect stay readable. Those frames live
in `FRAMES` as `google-http-syn`, `google-http-req` and `google-http-301`.

Colour means layer, on every slide: Ethernet blue, ARP yellow, IPv4
orange, ICMP teal, TCP purple, HTTP green, TLS red. Grey means the layer
is explained on another slide. Within a layer, fields alternate
between a banded shade and a plain one (filled and hollow chips in the
table), so the boundaries show without extra colours.

Field names with a dotted underline jump to the slide that introduces
that layer or struct (for example, "IPv4 header" on the HTTP slide opens
the ping's IPv4 breakdown). The jump adds a browser history entry, so
Back (⌘[ or Alt+←) returns to where you were.
